# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [1.0.0] — 2026-11-01

### Added
- A complete fictional ISO/IEC 27001:2022 ISMS cycle for Northwind Logistics FZ-LLC: context, interested parties
  (including UAE PDPL and the UAE IA Regulation), scope, policy and RACI.
- Risk methodology (5×5, acceptance criteria), 20 assets, 25 risks with inherent, residual and target scores, and a
  24-action risk treatment plan, generated as CSV and as an Excel workbook with live formulas and heat maps.
- Statement of Applicability for all 93 Annex A controls with justifications and links to risks and requirements.
- Internal audit programme, audit report (2 nonconformities, 5 observations, 16 evidence references) and
  corrective-action log.
- Management review minutes covering every clause 9.3 input and output, KPI/KRI table, metrics pack and
  continual-improvement log.
- `scripts/build_isms.py` (deterministic build), `scripts/validate_isms.py` (consistency checks), unit tests and CI.
- Governance files: licence, code of conduct, security policy, contributing guide, Dependabot.
